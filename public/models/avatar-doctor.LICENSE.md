# Avatar Doctor — licence et provenance

Le modèle `avatar-doctor.glb` est une adaptation du modèle d’exemple
`mpfb.glb` du projet open source
[TalkingHead](https://github.com/met4citizen/TalkingHead).

- Base humaine : MPFB / MakeHuman Community
- Licence de la base : CC0 1.0 (domaine public)
- Adaptation : tenue médicale, matériaux, cadrage et optimisation Web
- Rig facial : blendshapes ARKit et 15 visèmes Oculus

La licence CC0 autorise l’utilisation, la modification et la redistribution,
y compris dans une application commerciale.
